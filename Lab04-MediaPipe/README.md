# Lab 04 — MediaPipe

This lab is distributed as two separate, self-contained Vite projects:

```text
Lab04-MediaPipe/
├── starter/    student project with numbered TODOs
└── solution/   completed instructor project
```

## Student project

Open `starter/` in VS Code and follow [starter/README.md](starter/README.md). The exercise files are:

- `starter/src/student/task1-hand-landmarker.js`
- `starter/src/student/task2-gesture-recognizer.js`

## Instructor solution

The completed implementation and its run instructions are in [solution/README.md](solution/README.md).

Each folder has its own `package.json`, lockfile, local MediaPipe models, WASM runtime, source code, validation script, and Vite commands. Run npm commands from the version you intend to use.
