Variants use different facts: A asks how many primitive types form the vessel; B asks how many brown doors the archive has; C asks for the torus-knot parameters. Each task also asks the person to close information and teleport to the valid floor.

Counterbalance by alternating baseline-first and student-first across participants. Keep the same input mode, room setup, and task wording within a comparison, but use a different exhibit variant to reduce recall.

## Self-test fallback

If working alone, screen-record one baseline and one student attempt, speak observations aloud, and use the same measures. Label these **self-test** results; they are formative checks, not independent user evidence.
